# Main screen and alternate screen

`TuiMainScreen` and `TuiAltScreen` extend one base (`TuiBase`). The base owns what is the same in both: the render scheduler and its pacing, resize debounce, focus and input routing, overlay compositing, fake-cursor resolution and cursor extraction, line resets, row clipping and trailing-blank trimming, and the synchronized-output markers. Each mode owns how a frame reaches the terminal.

| Concern    | Main screen                                                                                             | Alternate screen                                                                                                 | Why it differs                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Rows       | The whole document, past the terminal height; the top scrolls into the terminal's scrollback.           | Exactly the terminal's rows; the application owns the scroll position.                                           | Scrollback belongs to the terminal only on the main screen.                             |
| Diff       | First to last changed row, then `\r\n` writes relative to the hardware cursor; a shrink collapses rows. | Every changed row is addressed absolutely (`ESC[row;1H`); a block shift is scrolled in place when it saves rows. | Rows above the viewport cannot be rewritten once scrolled out; an addressed screen can. |
| Cursor     | Tracks the hardware cursor row relative to the document.                                                | Remembers only whether the cursor and its position changed.                                                      | Absolute addressing needs no running position.                                          |
| Images     | Kitty image rows reserve space by moving the cursor; ids deleted when their rows change.                | Uploaded images are cached and re-placed by id; offscreen ones are evicted.                                      | A scrolling screen needs placements that survive scrolling.                             |
| Row marks  | Shell-integration zone marks stay in the output.                                                        | Zone marks are stripped.                                                                                         | The alternate screen has no scrollback for a shell to navigate.                         |
| Decoration | Overlays only.                                                                                          | Search highlights, jump-to-end label, selection, flashes, then images budget.                                    | Only the alternate screen draws application-owned chrome.                               |

The shared row-level pieces are `tui/row-text.ts` (erase a line, write its trimmed text) and `tui/row-arrays.ts` (`mapRowsReusing`, `arrayWithPrefix`). A change to how a row is written belongs there, so both modes stay in step.
