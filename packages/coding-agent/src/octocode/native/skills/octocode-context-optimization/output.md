# Output

A short report in task terms.

- **Skills:** each skill rewritten with its size before and after (from `octocode context check`), the listing total before and after (from `octocode context list`), any point of a source description the rewrite words differently enough to need a look, skills left on their source description and why, and whether `octocode context apply` ran.
- Checks not run (for example a live small-model evaluation).

Save the overrides file and the report to `<workspace>/.octocode/agent/octocode-context-optimization/`.
