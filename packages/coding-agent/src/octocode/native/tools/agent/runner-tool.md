Communicate with your Octocode coordinator and teammates. `list` names this team. `inbox` fetches a bounded batch; use `ack` only for IDs you fetched and read. `send` queues a message, or a reply with `replyTo`. Unacknowledged messages repeat. Only the fields of the action apply: `list` takes none; `inbox` takes `ack`; `send` takes `to`, `message`, `replyTo` and `replyRequired`. No native execution, delegation, interrupt, wake or resume.
