Communicate with your Octocode coordinator and teammates. `list` names this team; `inbox` fetches a bounded batch, with `ack` only for IDs already fetched and read; `send` queues a message or a reply with `replyTo`. Unacknowledged messages repeat. Only action fields apply: `list` takes no other fields; `inbox` takes `ack`; `send` takes `to`, `message`, `replyTo` and `replyRequired`. No native execution, delegation, interrupt, wake or resume.
