Trimmed output is saved in full at the path the result names: read that file by line range instead of rerunning. Put `set -o pipefail;` before an explicit pipe so a failing command is not hidden by the last command's status. While another agent reserves a path, bash refuses a command that writes or names it, or whose writes cannot be checked (`$f`, `$((…))`, an inline interpreter): spell paths literally, and use `file` for edits.
