The commands below are for a quick look at one known file or log, a command's own output, binaries, processes, git and CI, and hosts without declared search and read tools.
Host: {{os}} {{arch}}. On PATH: {{present}}{{#if missing}}; not found: {{missing}}{{/if}}. gh: {{gh}}. Check any other tool with `command -v` before relying on it.
Host notes: {{#if darwin}}BSD tools: `sed -i ''` or `-i.bak`, `stat -f '%z %Sm'`, `date -v-1d`, `shasum -a 256`; no `grep -P` (use `rg -P`) and no GNU `timeout` (set this tool's timeout); top CPU `top -l 1 -o cpu -n 15`; listening ports `lsof -nP -iTCP -sTCP:LISTEN`.{{/if}}{{#if linux}}GNU tools: `sed -i`, `stat -c '%s %y'`, `date -d yesterday`, `sha256sum`, `grep -P`; top CPU `ps aux --sort=-%cpu | head`; listening ports `ss -ltnp`.{{/if}}{{#if windows}}bash commands run in Git Bash with GNU tools; for Windows state use `type: powershell`: `Get-Process | Sort-Object CPU -Descending | Select-Object -First 15`, `Get-NetTCPConnection -State Listen`.{{/if}}{{#if otherOs}}check flags with `cmd --help` or `man`, since GNU and BSD options differ.{{/if}}
Find: `git ls-files | head`, `fd -e ts . src` (pattern first, then directory); recent changes `fd -t f --changed-within 1d` or `ls -lt | head`, a file's last commit `git log -1 --format='%h %ar %s' -- path`; before opening, `wc -l`, `file` and `du -sh` or `fd -S +1m` spot binary and generated files.
Quick looks at files and output: counts or names (`rg -c`, `rg -l`), then bounded hits (`rg -n -C2 pat | head -60`), then the span (`sed -n 'A,Bp'`); `cat` only a short file; in minified text, `rg -o '.{0,40}pat.{0,40}'` or `head -c 2000`; count test failures by the runner's marker (vitest `×`, `N failed`), not `FAIL` alone.
Strings: `rg -F` for a literal, `-w` for a whole word, `rg -o -r '$1' 'key=(\w+)'` to extract, `rg -oN pat | sort | uniq -c | sort -rn | head` to rank, `strings -n 8 file | rg pat` inside binaries, `cut`, `tr` and `awk -F` for fields; past three pipeline stages, write a short python or node script.
Structured output: `--json` with `jq` (`jq 'keys'`, `jq '.items | length'` before listing), `git diff --stat` or `--name-only` before a full diff; a capped result does not prove absence, so say what you capped.
Change and move: preview a substitution with `sed -E 's/a/b/g' f | diff f -` and apply it with the `file` tool when declared (else `sed -i.bak`); `mkdir -p` first, `git mv` keeps history, `mv -n` and `cp -n` never overwrite, `rsync -an src/ dst/` previews a tree copy; confirm with `git status -sb`.
Processes: `pgrep -l name` (`-f` matches whole command lines, which can be long), `ps -o pid,ppid,etime,%cpu,rss,command -p PID`, `lsof -nP -p PID` for its files and sockets; stop only processes you started (`kill PID`, `kill -9` only if it ignores that); run servers and watchers with background: true.
