# @octocodeai/octocode-common

Private workspace of host-free utilities shared by coding-agent, `packages/mcp` and `packages/acp`: JSON and text helpers, environment names, atomic and locked file writes, path and child-process helpers, the home folder shown as `~` (`home-tilde.ts`), estimated money as every surface writes it (`money.ts`: `≈$1.24`), regular-expression escaping (`regexp.ts`), the system opener for URLs and files (`open-target.ts`, never through a shell), terminal-text sanitizing and secret redaction (`sanitize.ts`), the SSRF-safe web guard (`web-guard.ts`), MCP and browser server names.

| Rule              | Detail                                                                                                                                                                                                                                                                                                                           |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Belongs here      | Needs only Node, its own dependencies and `contracts` (`common: ["contracts"]` in the package policy, enforced by `yarn run check:boundaries`)                                                                                                                                                                                   |
| Stays in the host | Anything needing configuration, agent directories, themes, settings, trust or the model registry; reach shared packages through an injected port                                                                                                                                                                                 |
| Not published     | A private library with its own `dist/`; the coding-agent build bundles it into its one bundle                                                                                                                                                                                                                                    |
| Importing         | Import `@octocodeai/octocode-common/<module>` by package name; the `"./*"` export resolves to source for the bundler, tests and tooling. Only db uses relative source paths (for example `../../common/src/text.ts`): its writer worker runs db source on plain Node, where the package name would load a possibly stale `dist/` |

Test: `yarn workspace @octocodeai/octocode-common run test`.
