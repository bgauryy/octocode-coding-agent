# Repository scripts

Run through the root `yarn run` script where one exists; the rest are manual tools or shared modules. The full verify table is in [DEVELOPMENT.md](../DEVELOPMENT.md#verify).

## Behind `yarn run`

| Script                                                                | Run with                                                                | Does                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `run-checks.mjs`                                                      | `check`                                                                 | Runs the listed root scripts in parallel, buffers output, reports every failure; notes files near the 400-line limit                                                                                                                                                                                             |
| `check-package-boundaries.mjs`                                        | `check:boundaries`                                                      | Package import policy; hosted workspaces (`mcp`, `acp`, `common`) never import host files; ratcheted layer baselines (`layer-import-baseline.mjs`: `core/` must not import `modes/`, `octocode/` or the MCP workspace; `octocode/` must not import `modes/`). A new edge and a stale baseline entry both fail    |
| `sdk-reachability.mjs`                                                | `check:boundaries`                                                      | Fails when the headless session factory newly reaches `tui`, `webview` or `modes/` through static value imports, or a baselined edge (`sdk-reach-baseline.mjs`) is gone                                                                                                                                          |
| `check-db-boundary.mjs`                                               | `check:db-boundary`                                                     | Keeps `prepare`, `db.exec` and `node:sqlite` imports inside `packages/db/src/`                                                                                                                                                                                                                                   |
| `check-mcp-boundary.mjs`                                              | `check:mcp-boundary`                                                    | Keeps imports into `packages/mcp/src/` from other workspaces on its `api.ts` (the bundle entry may re-export the client subpaths)                                                                                                                                                                                |
| `check-browser-smoke.mjs`                                             | `check:browser-smoke`                                                   | Bundles browser-facing exports with Rolldown: no Node imports, selective-provider tree shaking                                                                                                                                                                                                                   |
| `build-workspace-state.mjs`                                           | `generate:workspace`, `check:workspace`                                 | Builds the webview page bundle into `packages/webview/src/state.generated.ts`                                                                                                                                                                                                                                    |
| `generate-favicon.mjs`                                                | `generate:favicon`, `check:favicon`                                     | Generates the favicon module and checks it is fresh                                                                                                                                                                                                                                                              |
| `build-coding-agent.mjs`                                              | `build` in `packages/coding-agent`                                      | One Rolldown bundle (`dist/bundle/`) with small launchers and the database writer's worker (`db-writer-worker.js`), then runtime assets, native helpers, licenses and `THIRD_PARTY_NOTICES.md` (`third-party-notices.mjs`)                                                                                       |
| `stage-bash-parser.mjs`                                               | coding-agent `build`                                                    | Stages the Bash parser                                                                                                                                                                                                                                                                                           |
| `stage-binary.mjs`                                                    | coding-agent `build:binary`, `build-binaries.sh`                        | Stages what a compiled binary reads beside itself: themes, export template, roles, native skills (`stage-coding-agent-skills.mjs`), native helpers                                                                                                                                                               |
| `generate-coding-agent-install-lock.mjs`                              | `install-lock:coding-agent`, `check:install-lock:coding-agent`          | Installer lock; see [install-lock](../packages/coding-agent/install-lock/README.md)                                                                                                                                                                                                                              |
| `diff-model-catalog.mjs`                                              | `diff:model-catalog`                                                    | Compares model catalogs                                                                                                                                                                                                                                                                                          |
| `profile-coding-agent-node.mjs`                                       | `profile:tui`, `profile:rpc`                                            | Profiles the CLI under Node                                                                                                                                                                                                                                                                                      |
| `measure-unfocused-cpu.mjs`                                           | `measure:unfocused-cpu ghostty\|terminal`                               | Terminal CPU with 1, 4 and 8 unfocused synthetic sessions: the old 200 ms spinner cadence against the paused animation clock; macOS, opens background windows, refuses at 1-min load 15 or more unless `--force`                                                                                                 |
| `pack-packages.mjs`, `check-package-install.mjs`                      | `pack:packages`, `check:package-install`                                | Packs the public package; installs the packed result and smoke-tests the CLI                                                                                                                                                                                                                                     |
| `local-release.mjs`                                                   | `release:local`                                                         | Local release candidate                                                                                                                                                                                                                                                                                          |
| `full-run-lock.ts`                                                    | `run-checks.mjs`, vitest global setup (`vitest.run-lock.global.ts`)     | One full suite or check at a time on this host: a second waits, naming the holder; a dead holder's lock is taken over (`node scripts/full-run-lock.ts --status` exits 0 when the lock is free, removing a dead holder's lock, and 1 naming the holder: use it as a `wait` check instead of testing `owner.json`) |
| `test-workspaces.mjs`                                                 | `test` (`./test.sh` wraps it in isolation)                              | Script tests plus every workspace's tests, continuing past failures, then lists them                                                                                                                                                                                                                             |
| `release.mjs`, `sync-versions.js`, `publish.mjs`, `release-notes.mjs` | `release:*`, `version:*`, `publish`, `publish:dry`, `release:fix-links` | Versioning, notes, publishing. `publish.mjs` gates on a clean tree, dependency versions on npm, tarball checks (`publish-stage.mjs`) and an install plus real session from the tarball (`publish-preflight.mjs`)                                                                                                 |

## Manual tools

| Script                                                  | Does                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agent-eval/`                                           | Decides whether an agent change ships, checks agents understand their instructions, and reports a baseline from stored sessions: [README](agent-eval/README.md)                                                                                                                                                                                                                               |
| `agent-capture/`                                        | Records the exact requests Claude Code, Codex or Octocode send, against a local mock with a dead proxy (no network, no cost), and sizes them per part and tool: [README](agent-capture/README.md). Tests run with `yarn run test:scripts`                                                                                                                                                     |
| `auto-octocode.sh`                                      | Runs octocode from this checkout's latest build (install steps in its header)                                                                                                                                                                                                                                                                                                                 |
| `build-binaries.sh`                                     | Builds platform binaries                                                                                                                                                                                                                                                                                                                                                                      |
| `create-source-archive.sh`                              | Deterministic source archive for a GitHub release                                                                                                                                                                                                                                                                                                                                             |
| `publish-release-announcement.mjs`                      | Publishes the release announcement                                                                                                                                                                                                                                                                                                                                                            |
| `stage-registry-release.mjs`                            | Stages a release in a disposable registry ([DEVELOPMENT.md](../DEVELOPMENT.md#validate-a-registry-release-candidate))                                                                                                                                                                                                                                                                         |
| `use-local-packages.mjs`                                | Points a consumer project at locally packed packages                                                                                                                                                                                                                                                                                                                                          |
| `generate-thinking-capabilities.mjs`                    | Generates thinking-capability data from a model catalog                                                                                                                                                                                                                                                                                                                                       |
| `profile-render-backpressure.mjs`                       | Compares TUI render schedulers against a slow terminal                                                                                                                                                                                                                                                                                                                                        |
| `replay-session.mjs`, `replay-profile.mjs`              | Replays a recorded session file through a real session offline (recorded replies and tool results, temporary home and database) and writes a report to `.octocode/tmp/`; `--profile` and `--heap-prof` add a CPU profile summary by owner and hotspot. The committed fixture replays in `test:e2e` (`e2e-replay.test.ts`). Real sessions hold private content: never commit one or its report |
| `packages/coding-agent/scripts/export-agent-prompts.ts` | Exports native role prompts and tool declarations as fixtures: `yarn exec node --import ./packages/coding-agent/scripts/source-resolver.ts packages/coding-agent/scripts/export-agent-prompts.ts <output-directory> [captured-mcp-catalog.json]`. Isolated configuration, no model calls; the optional catalog adds captured MCP declarations without running tools                           |
